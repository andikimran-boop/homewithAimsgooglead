# Semakan Jualan Rumah — landing page

Google Ads landing page for Homes with AIMS.

## Upload
1. Upload ALL files in this folder, including the hidden .nojekyll file.
   - Option A: as its own repo → Settings → Pages → Deploy from branch: main / root.
   - Option B: inside your main site repo as a folder named `semakan` → live at homeswithaims.com/semakan/
2. All photos are in img/ (couple photos + sold-1…6.webp). Replace any of them using the same filename.

## Before launch
- Replace `AW-XXXXXXXXX` (2 places) and `AW-XXXXXXXXX/XXXXXXXX` in index.html with your Google Ads IDs.
